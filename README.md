# 节令鼓 · 鼓法回看

团员回看表演和练习影片、看鼓谱、跟着打的网站。整个网站只有一个网页文件，免费放在 GitHub Pages。

| 文件             | 用途                                               |
| ---------------- | -------------------------------------------------- |
| `index.html`     | 整个网站                                           |
| `apps-script.gs` | Google 表格的后台：读影片列表，新增和编辑影片      |
| `videos.json`    | 示例数据，`SCRIPT_URL` 留空时用                    |

## 设定 Google 表格（只做一次）

1. 用个人 Google 帐号新建一个表格。第一行写：`类型` `标题` `日期` `链接` `鼓谱`（一格一个）。
2. 「扩展程序」→「Apps Script」。删掉原本的代码，贴上 `apps-script.gs` 的全部内容，然后保存。
3. 「项目设置」（齿轮）→「脚本属性」→ 新增：属性 `PASSCODE`，值是团员密码（8 个字以上）。没设密码的话，谁都不能保存。
4. 「部署」→「新部署」→ 类型选「网页应用」→ 执行身份「我」→ 谁可以访问「任何人」→ 部署，然后按「授权」。
5. 复制「网页应用」的网址，贴到 `index.html` 里的 `SCRIPT_URL`。

改了 `apps-script.gs` 以后：「部署」→「管理部署」→ 编辑 → 版本选「新版本」→ 部署。网址不会变。

团员不需要表格的权限，只需要团员密码。表格只给管理的人用，例如一次贴很多旧影片。

## 新增影片

网站右上角「＋ 新增影片」→ 贴 YouTube 链接 → 输入团员密码 → 保存。
同一个影片再保存一次 = 更新那一行，不会重复。影片页的「✎ 编辑」可以改鼓谱，也可以按「删除影片」（要团员密码）。

影片在 YouTube 设成「不公开」：网站可以播放，但在 YouTube 搜不到。拿到链接的人都能看。

## 鼓谱写法

`R` `L` `B` = 右手、左手、双手打鼓芯；`r` `l` `b` = 打鼓边；`-` = 空拍。
空格分开每一拍，`|` 分开每一小节。一拍里写两个字母 = 这一拍打两下。其他文字照原样显示。

例子：`R L RL B | r l rl b`

## 打鼓

手机：点鼓芯「咚」，点鼓边「嗒」。电脑：`F` 左手鼓边、`V` 左手鼓芯、`B` 右手鼓芯、`H` 右手鼓边，可以在「改按键」改。
