# 节令鼓 · 鼓法回看

团员回看表演和练习影片、看鼓谱、跟着打的网站。整个网站只有一个网页文件，免费放在 GitHub Pages。

| 文件             | 用途                                               |
| ---------------- | -------------------------------------------------- |
| `index.html`        | 整个网站                                                   |
| `sound-maker.html`  | 鼓声调音台：自己调鼓芯和鼓边的声音，保存给全团用           |
| `drum.js`           | 两个网页共用：`SCRIPT_URL` 和发出鼓声的程序                |
| `apps-script.gs`    | Google 表格的后台：影片列表、新增、编辑、删除，还有鼓声设定 |
| `videos.json`       | 示例数据，`SCRIPT_URL` 留空时用                            |

## 设定 Google 表格（只做一次）

1. 用个人 Google 帐号新建一个表格。第一行写：`类型` `标题` `日期` `链接` `鼓谱`（一格一个）。
2. 「扩展程序」→「Apps Script」。删掉原本的代码，贴上 `apps-script.gs` 的全部内容，然后保存。
3. 「项目设置」（齿轮）→「脚本属性」→ 新增：属性 `PASSCODE`，值是团员密码（8 个字以上）。没设密码的话，谁都不能保存。
4. 「部署」→「新部署」→ 类型选「网页应用」→ 执行身份「我」→ 谁可以访问「任何人」→ 部署，然后按「授权」。
5. 复制「网页应用」的网址，贴到 `drum.js` 里的 `SCRIPT_URL`。

改了 `apps-script.gs` 以后：「部署」→「管理部署」→ 编辑 → 版本选「新版本」→ 部署。网址不会变。

团员不需要表格的权限，只需要团员密码。表格只给管理的人用，例如一次贴很多旧影片。

## 新增影片

网站右上角「＋ 新增影片」→ 贴 YouTube 链接 → 输入团员密码 → 保存。
同一个影片再保存一次 = 更新那一行，不会重复。影片页的「✎ 编辑」可以改鼓谱，也可以按「删除影片」（要团员密码）。

影片在 YouTube 设成「不公开」：网站可以播放，但在 YouTube 搜不到。拿到链接的人都能看。

## 鼓谱写法

`R` `L` `B` = 右手、左手、双手打鼓芯；`r` `l` `b` = 打鼓边；`-` = 空拍。
空格分开每一拍，`|` 分开每一小节。一拍里写两个字母 = 这一拍打两下。其他文字照原样显示。

例子：`R L RL B | r l rl b`

几排打不一样时，在行前面写排号，一排一行，连着写（`第1排:`、`一:` 也可以）：

```
1: R L R L | B - B -
2: r l r l | B B B -
```

连着的排号行会对齐显示。「跟着打」时这几排一起打，可以勾选要听哪几排。没写排号的行跟以前一样。
每一排只写一行；排号重复（又写 `1:`）就是新的一段。

## 用鼓写鼓谱

新增或编辑影片时，鼓谱下面有「🥁 用鼓写鼓谱」：

1. 要改哪里，就在鼓谱预览点那一行（或那一组）；不点 = 加在最后。选了的话，长度跟它一样，录完会自己停。
2. 选「不分排」或「第几排」，设定速度、每小节几拍、最细到每拍几下。
3. 按「● 开始录」：先响一小节预备拍，节拍器每拍都会响（第一拍比较高），画面会数「第几小节 · 第几拍」。用鼓或按键打。
4. 录完后可以：点音符再点空格移过去、◀ ▶ 移一格、🗑 删除、▶ 听；觉得整体太早或太晚，拉「整体移动」。改「最细到」或「整体移动」会从原本录的重新排。
5. 按「写进鼓谱」，再按「保存」。

写进去的规则：没选 = 加在最后；选了一行 + 不分排 = 换掉那一行；选了一行 + 第 N 排 = 原本那行变 `1:`，新的变 `N:`；选了一组 + 第 N 排 = 换掉或加入那一排。

## 打鼓

手机：点鼓芯「咚」，点鼓边「嗒」。电脑：`F` 左手鼓边、`V` 左手鼓芯、`B` 右手鼓芯、`H` 右手鼓边，可以在「改按键」改。

## 调鼓声

打鼓页的「🔊 自己调鼓声」打开调音台（`sound-maker.html`）。每个鼓声 = 最多 4 个音层 + 1 个敲击声，每样都可以调。
「最大音量」超过 1 会破音。按「保存给全团用」（要团员密码）以后，全团的打鼓和跟着打都用新的鼓声。
鼓声存在 Apps Script 的脚本属性 `SOUNDS`，不用改代码，也不用 push。
